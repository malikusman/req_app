# Accounts Payable Procedure — DocsFirst Ltd

## Invoice intake

AP clerks re-enter vendor invoices from email into SAP. Manual data entry and spreadsheets remain the backup when SAP is slow.

## Approvals

Invoices over threshold need triple approval. Approval bottlenecks appear when managers are offline; teams coordinate by email and meetings.

## Reconciliation

Finance reconciles SAP AP aging to a disconnected Excel tracker — classic data silos and matching work that burns hours each close.
