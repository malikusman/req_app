# ISO 9001 Quality Manual — DocsFirst Ltd

## Document control

Controlled procedures for quality management. Manual spreadsheet trackers are forbidden for controlled records after revision 4.

## Approval bottlenecks

Change requests require manager sign-off and quality director approval before release. Waiting on manager approval is the most common delay in document control.

## Systems

Master list lives in SharePoint; controlled copies are reconciled weekly against the ERP document register to avoid data silos and duplicate versions.

## Continuous improvement

Repetitive time-consuming work to copy-paste revision tables into Excel must be eliminated via workflow automation.
